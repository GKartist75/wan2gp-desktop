# Wan2GP Desktop Launcher (Electron) — RETIRED

> ⚠️ **This Electron edition is retired and no longer maintained. Please use the Tauri edition:**
>
> ## 👉 [Wan2GP Desktop Launcher Tauri](https://github.com/GKartist75/Wan2GP-Desktop-Tauri)
>
> Same launcher, same Wan2GP, same features — but a **~3 MB installer instead of ~150 MB**, faster startup, lower RAM usage (WebView2 engine already in Windows + compiled Rust backend).
>
> **Switching is painless:**
>
> 1. Download the installer from the [Tauri repo page](https://github.com/GKartist75/Wan2GP-Desktop-Tauri)
> 2. Install & launch it — it detects this Electron app and offers to remove it for you
> 3. Prefer doing it yourself? Uninstall this app via Windows Settings → Apps — your Wan2GP, models and settings stay untouched
> 4. Your Wan2GP install, models and settings carry over untouched — nothing to re-download
>
> ⭐ **Using the Tauri edition? Please [star it on GitHub](https://github.com/GKartist75/Wan2GP-Desktop-Tauri)** — it helps others find it.

## What was this?

The Electron-based desktop launcher for [Wan2GP](https://github.com/deepbeepmeep/Wan2GP) by deepbeepmeep — one-click install, per-GPU kernels, Auto-Tune, Deepy, plugin manager and updates for the WanGP generative video/image/audio toolkit on Windows.

The full documentation of this retired edition is preserved at [`docs/archive/README-electron-final.md`](docs/archive/README-electron-final.md) for reference.
