1
Pre-flight · install-plan

Resolve the Stack & Check Gates

The launcher maps your GPU to the exact torch / CUDA / kernel matrix before cloning — so you see what will install and any blockers up front.

  • Vendor → CUDA build, PyTorch version, attention kernels (see matrix →)
  • Driver gate: NVIDIA cu130 needs R580+; AMD ROCm needs ≥24.5; Intel Arc needs ≥31.x
  • Disk gate: free-space check (reports free GB; warns if low)
  • RAM/VRAM tiers (≥64 / ≥32 GB RAM, ≥24 / ≥12 GB VRAM)
Hard block only trips on an old NVIDIA cu130 driver or no disk — everything else is a soft compatibility warning.
2
Clone

Clone Wan2GP Repository

git clone --depth 1 https://github.com/deepbeepmeep/Wan2GP.git
Async (≤2 min, no app freeze). Leftover models folder is stashed, clone runs fresh, then folded back so you keep existing downloads.
3
Environment

Create Python Environment

Two modes — pick in the installer:

  • venv — needs py -3.11; if missing, the launcher uses an uv-managed isolated Python 3.11 shim (no global install)
  • uv — simplest, no Python required on the host
runSetup(['install','--env', env, '--auto'])
4
Dependencies

Install Requirements

pip install -r requirements.txt
Phases stream live: [1/3] Preparing Environment → pip install -r requirements. Packages resolved per your GPU profile from setup_config.json.
5
Post-install

Verify & Harden

  • AMD on Windows → pin numpy==1.26.4 (ROCm torch compat)
  • Ensure huggingface_hub is installed
  • Install hf_xet (Xet Storage — faster model downloads; optional)
  • syncKernelWheels — verify GPU kernel wheels landed (Sage / Flash / Sparge / Nunchaku+GGUF) and fix any silent mismatch
"Installation complete" only shows after all of the above finish.
▶
Launch

Run the Web UI

Confirms wgp.py exists + active env + python, then builds the launch args and starts Gradio.

--server-port 7860 --server-name localhost --advanced --multiple-images [--share] [--gpu cuda:N]
Opens at http://localhost:7860 — in your browser or the embedded webview. Multi-GPU picks --gpu cuda:N; --share only when enabled in settings.

Gates & Warnings

Hard block — old NVIDIA cu130 driver (< R580) or insufficient disk. Install button disabled until resolved.
Soft warning — AMD driver < 24.5, Intel Arc < 31.x, low RAM/VRAM. Install continues but may fall back to CPU.
OK — driver current, disk sufficient, GPU profile resolved.
Gates are pre-flight only; they never silently abort the install.
