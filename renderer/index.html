GGUF CUDA Kernel

Controls for the llamacpp_gguf_cuda wheel (GGUF models). Applies on next launch. Matmul mode picks the FP16/BF16 multiply policy; Stream-K (default on) enables CUDA-graph-safe Stream-K; BF16→FP16 restores the legacy path; Disable turns the GGUF CUDA kernels off entirely.

Repair Settings

If saving settings in Wan2GP fails with "Value: N is not in the list of choices: [0, 1]", a saved value is out of range for a dropdown (usually from an older version or imported settings). This scans models/_settings.json and all *_settings.json files and resets out-of-range values to valid ones. Originals are backed up as *.bak-repair.

Uninstall Wan2GP

Removes the Wan2GP app, its Python environment, and all installed packages. Downloaded models can be kept. The Desktop launcher itself stays installed.

Share Link

If you see the error "When localhost is not accessible, a shareable link must be created" when launching, that is Gradio's IPv4/IPv6 self-check failing — fix it first with Bind Address → localhost (below) or by adding --server-name localhost to Extra Launch Args. Only if that does not help, enable this to create a public Gradio tunnel (your server becomes reachable from the internet).

Extra Launch Args

Server Port

Port for the Wan2GP web interface. Default: 7860. Changes apply on next launch.

GPU Device

On machines with multiple GPUs (integrated + dedicated, or dual NVIDIA), choose which one runs generation. Passed as --gpu cuda:N on launch. Changes apply on next launch.

Bind Address

Address Wan2GP binds and connects to. localhost resolves to whatever your PC uses (IPv4 or IPv6) and matches Gradio's own startup check — use it if you saw "When localhost is not accessible…". 127.0.0.1 is a strict-IPv4 fallback for proxy/VPN setups. Changes apply on next launch.

Arguments passed to wgp.py on launch. See CLI docs for all options. Changes apply on next launch.
